## 買い替えの動機

個人開発のモチベーション向上と、M1 Airの性能不足が主な理由。

特にAntigravity使用中に頻繁にフリーズするのが深刻だった。
メモリ容量も「8GB」しかなく、マルチタスクには厳しい状況。
ストレージも「256GB」しかなく、開発環境を整えると余裕がなくなっていた。
ただし、バッテリー持ちは全く問題なかった。

## M4 Airを選んだ理由

### Amazonのブラックフライデーセールで激安（メモリ高騰の影響なし）

Amazonのブラックフライデーセールで過去最大級の値下げが実施され、型落ちでもないのに投げ売り状態だった。
「256GB / 16GB」モデルなら13万円台で購入でき、この価格帯としては破格の性能。
数年間常用することを見据えて、「512GB / 16GB」モデルを選択した。

### 携行性、性能ともに優れている

#### スペック比較表

| 項目 | M1 MacBook Air | M4 MacBook Air |
|------|----------------|----------------|
| **高さ** | 0.41〜1.61cm | 1.13cm |
| **幅** | 30.41cm | 30.41cm |
| **奥行き** | 21.24cm | 21.5cm |
| **重量** | 1.29kg | 1.24kg（約50g軽量化） |
| **画面サイズ** | 13.3インチ | 13.6インチ |
| **ディスプレイ** | Retina | Liquid Retina |
| **解像度** | 2,560 × 1,600px（227ppi） | 2,560 × 1,664px（224ppi） |
| **CPU** | 8コア | 10コア |
| **GPU** | 7〜8コア | 8〜10コア |
| **性能** | - | M1比で最大2倍（Apple公式） |

M4 Airの方がわずかに薄く、約50g軽量化されている。
インカメラの切り抜き部分がノッチになりメニューバーと融合したことで、ベゼルが薄くなり、本体サイズはほぼそのまま、画面が大型化した。

### メモリの最低容量が「8GB」から「16GB」へ強化

M4世代からメモリの最低容量が16GBに引き上げられ、今後数年間の常用に耐えられるスペックになった。これは大きな進化といえる。

## 買い替えて感じたメリット・デメリット

### メリット

#### 性能アップによる開発効率の向上

カクつく頻度が明らかに減少した。Safariのタブ切替がスムーズになり、技術選定やWebでの調査時の快適性が大幅に向上。
地味にストレスに感じていた点だったので嬉しい改善だ。

Antigravityのエージェントマネージャを並行稼働させても落ちにくくなった。
エージェントマネージャ上で複数プロジェクトを並行実行していると急激に重くなるが、M1 Airではメモリ不足でフリーズしていたのに対し、M4 Airではギリギリ実行可能になっている。

アプリ間の切り替えも高速化した。
例えばAntigravityやClaude Codeを並行稼働させつつブログの下書きを作成する場合、それぞれのウィンドウでボタン操作や出力確認が必要なので頻繁に切り替えるが、一瞬で画面が切り替わるのでストレスがない。

#### バッテリー持続時間の強化

先述の開発作業を並行稼働させていても、バッテリーは半日以上持続する。
むしろClaude Code Proプランのトークン上限の方が先に切れるほどだ。

#### 画面サイズの大型化

M1 Airは画面サイズが小さいため、基本的に自宅では外部モニターを使用していた。
M4 Airでは画面サイズが13.3インチから13.6インチに大型化し、数値の変化以上に体感での視認性が向上した。
自宅でも外部モニターを使用せず内蔵ディスプレイで作業する頻度が増え、場所を問わず作業できるようになった。
気分で作業場所を移せるのは大きなメリットで、出先でも自宅と同じ感覚で作業できる。

### デメリット

#### デザインがやや野暮ったい

M1 Airのデザインは初代Air同様、伝統のウェッジシェイプを採用していた。
しかし、M2 Airからスクエアデザインが採用され、全体の厚さが均一でフラットに。
体感として、手に取った時に薄さがあまり感じられず、やや野暮ったいデザインに感じる。
正直昔のデザインの方が好きだが、性能には変えられないので我慢している。

#### M5 Airの発表が近い（と思われる）

昨今の円安情勢にメモリ品薄による価格急騰も相まって、M5 Airの日本での価格上昇は避けられないと予想される。
M4とM5の変更点については噂レベルだが、数％〜十数％の基本性能向上に留まると思われる。
価格反映前の今が安く購入できるラストチャンスかもしれない。

## まとめ

M1 AirからM4 Airへの乗り換えは大正解だった。
特に開発作業における快適性が大幅に向上し、メモリ不足によるフリーズから解放されたのが最大のメリットだ。デザイン面では好みが分かれるところだが、性能とのトレードオフとして許容できる範囲だ。

M5 Airの発売も近いと予想されるが、円安やメモリ価格高騰を考慮すると、今がM4 Airをお得に購入できるタイミングかもしれない。
